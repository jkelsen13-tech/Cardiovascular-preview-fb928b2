# Heart v3 preview

This is a prepared heart-only static application. It has not been published by this packaging step.

Serve the parent directory over HTTP and open `/heart-v3-preview/`. For example, run `python3 -m http.server 8792 --directory /path/to/parent` and visit `http://127.0.0.1:8792/heart-v3-preview/`. Opening the HTML directly with `file://` is not the tested setup.

Use the launch button, then Play or phase steps. Routes A–D cover valves, wall-to-sarcomere, conduction/cell voltage, and coronary exchange. Return restores the chosen gross view. Preview menu disposes the active renderer. Text/2D mode retains every route.

The preview writes only `cmt.heart.preview.progress.v1`. A path under an existing website shares that website’s origin, so a separate key—not the folder name—provides progress separation. No existing private, respiratory, quiz or mock progress is imported, moved or reset.

The source/adaptation manifest identifies the exact packaged bytes. Model, anatomical and microscopic evidence have different limits. Cloud browser verification does not establish physical iPad Safari performance or specialist approval. See the technical notes and copyright notices.

The package contains no course PDFs, screenshots, university recordings, old quiz, respiratory module or private lesson navigation. Source citations open only when selected; the runtime loads local assets.
